# Natt

Application mobile de gestion de tontines au Sénégal : la gérante crée sa tontine, partage un code, et Natt s'occupe des rappels, du suivi des paiements et de l'ordre des tours. L'argent va directement des membres à la gérante (Wave, Orange Money) : Natt ne le détient jamais.

- Stack : Expo (React Native) + Supabase
